# ToolOrbit

[ToolOrbit](https://toolorbit.site) 面向 Etsy 卖家，用于在发布前准备 Listing、检查商品素材和核算定价。

站点将费用与定价计算器，同 AI 辅助的 Listing、关键词、商品图和报关资料工具放在同一工作流中。计算器在浏览器内处理；AI 工具会把用户提交的必要内容发送到已配置的模型服务，返回可编辑的草稿或检查结果。

## 本地开发

环境要求：Node.js 20 或更高版本，以及 npm。

```bash
npm install
cp .env.example .env.local
npm run dev
```

开发服务器地址为 `http://localhost:8001`。

### 环境变量

| 变量 | 用途 |
| --- | --- |
| `MINIMAX_API_KEY` | AI 文案、图片检查和图片生成功能所需。 |
| `MINIMAX_TEXT_MODEL` | 可选的文本模型覆盖项。 |
| `MINIMAX_VISION_MODEL` | 可选的视觉模型覆盖项。 |
| `MINIMAX_IMAGE_MODEL` | 可选的图片模型覆盖项。 |
| `NEXT_PUBLIC_GA_MEASUREMENT_ID` | 可选的 GA4 衡量 ID。 |
| `NEXT_PUBLIC_GOOGLE_ADSENSE_CLIENT` | 可选的 AdSense 发布商 ID。 |

`DEEPSEEK_API_KEY` 和 `ZHIPU_API_KEY` 仍保留在环境变量示例文件中以兼容部署配置；当前公开 AI 路由使用 MiniMax 配置。

## 常用命令

| 命令 | 用途 |
| --- | --- |
| `npm run dev` | 在 8001 端口启动 Next.js 开发服务器。 |
| `npm run lint` | 生成 Next 类型并执行 TypeScript 检查。 |
| `npm run build` | 生成 sitemap、构建应用并预压缩静态资源。 |
| `npm run deploy:local` | 创建本地部署包和归档文件。 |

## 项目结构

```text
src/app/                  Next.js 路由和 API 处理器
src/views/tools/          工具界面和计算逻辑
src/data/tools-meta.ts    公开工具注册表
src/constants/blogData.ts 已发布文章注册表
src/lib/                  元数据、sitemap、导航和共享辅助逻辑
public/articles/en/       已发布指南的 Markdown 源文件
```

## 数据处理说明

- 费用和定价计算器在浏览器内处理输入值。
- AI Listing、图片、素材检查和 HS 编码功能会将完成任务所需的输入发送到已配置的模型服务。
- 计算结果只用于估算。AI 结果是草稿或检查辅助信息。发布或提交前，请核对商品事实、平台规则、费用和合规要求。
