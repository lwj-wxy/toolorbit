## 隐私与安全

- 多数工具在浏览器本地执行，文件、文本和开发数据默认留在你的设备上。
- JSON、哈希、图片、PDF、编码、加密和常见计算任务不需要账号。
- AI 工具需要把你的输入发送给模型服务以生成结果。
- 站点使用 HTTPS，并配置 Content Security Policy 等基础安全策略。
