# ToolOrbit — 免费在线工具箱

**[toolorbit.site](https://toolorbit.site)** · 隐私优先，基于浏览器的开发者、创作者和电商卖家实用工具集。

无需注册，无需上传服务器。每个工具都通过 Web API 和客户端计算在你自己的浏览器中本地运行。你的数据始终留在你的设备上。

## 隐私与安全

- **所有计算均在本地执行**——JSON 解析、哈希生成、图片处理、PDF 操作和加密解密全部通过 Web API 在浏览器中完成。绝不将任何数据上传到服务器。
- **无需注册账号**——所有工具即开即用。
- **Content Security Policy** 标头限制脚本来源并阻止内联执行。
- **全站 HTTPS**，启用 HSTS preload 和安全默认配置。

## 本地开发

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 生产构建
npm run build

# 启动生产服务器
npm start
```

浏览器访问 [http://localhost:3000](http://localhost:3000)。
