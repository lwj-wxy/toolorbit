# 电商支付处理费指南：Etsy、Stripe、PayPal 与真实利润

电商卖家经常用错误方式比较费用。Etsy 费用、Stripe 费用和 PayPal 费用不是同一类成本。Etsy 是平台型费用，覆盖流量、搜索、交易和支付基础设施；Stripe 和 PayPal 主要是支付处理费用，其中 PayPal 还可能包含钱包、发票、国际交易和货币转换等层。

真正有用的问题不是「哪个费率最低」，而是：扣除费用、流量成本、转化率、客服和退款后，哪个渠道留下的真实利润更高？

## 平台费用和支付处理费不是一回事

Etsy 是 marketplace。它的费用包含平台搜索曝光、买家信任、listing 基础设施、交易流程和支付处理。独立站使用 Stripe 或 PayPal 收款，并不会自动带来买家。你可能支付更低的交易费，但要自己承担广告、内容、邮件、SEO 和客服成本。

可以这样理解：

| 渠道 | 费用主要覆盖什么 |
|------|------------------|
| Etsy | 平台流量、listing、交易层、支付、卖家工具 |
| Stripe | 卡和支付处理基础设施 |
| PayPal | 钱包 checkout、卡处理、买家信任、发票、payment link |

所以，直接拿 Etsy 综合费用和 Stripe 手续费比，只有在同时计算获客成本时才有意义。

## 从单笔订单利润开始

每个渠道都建议按同一公式核算：

```text
客户支付金额
- 平台费用
- 支付处理费
- 广告或获客成本
- 商品成本
- 运费和包装成本
- 退款与客服预留
= 真实贡献利润
```

## 示例：Etsy 与独立站

假设你卖一个 $50 商品，向买家收 $5 运费，直接成本 $18。

在 Etsy 上，你可能承担：

- 上架费
- 交易费
- Etsy Payments 付款处理费
- 可能的站外广告费
- 可能的监管运营费或货币转换费

在独立站，你可能承担：

- Stripe 或 PayPal 手续费
- 电商平台订阅费
- 插件或应用费用
- 支付争议风险
- 广告或内容获客成本
- 邮件营销和再营销工具

独立站支付手续费可能更低，但如果每笔订单都依赖广告获客，整体并不一定更便宜。

## 独立支付什么时候更有优势

独立站 checkout 更适合：

- 已经有复购客户
- 邮件列表能带来订单
- 客单价较高
- 买家经常购买组合包或订阅
- 需要更强 checkout 控制
- marketplace 费用压缩利润
- 想掌握客户数据和售后流程

这些情况下，Stripe 或 PayPal 的支付费通常比平台综合费用更容易消化。

## Etsy 什么时候仍然值得

Etsy 仍然适合：

- Etsy 站内搜索需求强
- 买家能通过 marketplace 搜到你
- 商品属于 handmade、vintage、craft 或礼品类
- 店铺受益于 Etsy 买家信任
- Etsy 转化率明显高于独立站
- 你还没有建立自己的受众

平台费用是否昂贵，关键取决于它是否帮你带来了原本拿不到的买家。

## 为什么还要比较 Stripe 和 PayPal

一旦你开始做独立 checkout，支付渠道选择就会影响利润。Stripe 在美国标准国内卡付款中通常费用更低；PayPal 可能在某些市场提升买家信任。很多店铺会同时提供两者，然后根据真实转化和费用报表决定主推哪个。

推荐流程：

1. 用 Etsy 计算器估算平台订单利润。
2. 用 Stripe 计算同一订单金额的净到账。
3. 用 PayPal 计算同一订单金额的净到账。
4. 用 Stripe vs PayPal 工具并排比较。
5. 给独立站场景加上获客成本。
6. 决定哪个渠道更值得投入。

## 核心要点

1. Etsy 费用和支付处理费属于不同类型成本。
2. Stripe 和 PayPal 降低的是支付处理层，不会自动解决流量成本。
3. 真实利润取决于客单价、直接成本、转化率、退款、广告和复购。
4. 卖家应使用真实场景比较，而不是只看表面百分比。
5. 健康的电商策略可以用 Etsy 获客，用独立站承接复购。
