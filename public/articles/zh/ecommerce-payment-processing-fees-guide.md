# 电商支付处理费指南：Etsy、Stripe、PayPal 与真实利润

电商卖家经常用错误方式比较费用。Etsy 费用、Stripe 费用和 PayPal 费用不是同一类成本。Etsy 是平台型费用，覆盖流量、搜索、交易和支付基础设施；Stripe 和 PayPal 主要是支付处理费用，其中 PayPal 还可能包含钱包、发票、国际交易和货币转换等层。

更有用的问题是：扣除费用、流量成本、转化率、客服和退款后，哪个渠道留下的真实利润更高？

## 平台费用和支付处理费不是一回事

Etsy 是 marketplace。它的费用包含平台搜索曝光、买家信任、listing 基础设施、交易流程和支付处理。独立站使用 Stripe 或 PayPal 收款，并不会自动带来买家。你可能支付更低的交易费，但要自己承担广告、内容、邮件、SEO 和客服成本。

可以这样理解：

| 渠道 | 费用主要覆盖什么 |
|------|------------------|
| Etsy | 平台流量、listing、交易层、支付、卖家工具 |
| Stripe | 卡和支付处理基础设施 |
| PayPal | 钱包 checkout、卡处理、买家信任、发票、payment link |

所以，直接拿 Etsy 综合费用和 Stripe 手续费比，只有在同时计算获客成本时才有意义。

### Etsy 费用结构详解

要了解你在 Etsy 上的真实支出，需要看到完整列表：

| 费用 | 典型金额 | 计算基础 |
|------|----------|----------|
| 上架费 | 每条 $0.20 | 每条 listing，每 4 个月或数量售完后续期 |
| 交易费 | 订单总额的 6.5% | 商品价格 + 运费 + 礼品包装 |
| Etsy Payments 处理费 | 3% + $0.25（美国） | 含税的订单总额 |
| 站外广告费 | 订单总额的 12% 或 15% | 归因于 Etsy 广告的订单（超 $10K 门槛后强制，或自主选择加入） |
| 监管运营费 | 因国家而异 | 买家位于受监管市场的订单 |
| 货币转换费 | 订单总额的 2.5% | listing 币种与支付币种不同的订单 |

一个 $50 商品加 $5 运费，仅 Etsy 交易费就是 `$55 × 6.5% = $3.58`。再加上支付处理费：`$55 × 3% + $0.25 = $1.90`。Etsy 专属费用合计约 $5.48（再加 $0.20 上架费）。这在订单总额中约占 11%，还没算商品成本、运费或广告费。

### 其他电商平台一览

| 平台 | 交易费（约） | 支付处理 | 备注 |
|------|------------|----------|------|
| Amazon Handmade | 15% | 已包含（Amazon Pay） | Handmade 免上架费；否则专业计划 $39.99/月 |
| eBay | 13.25%（多数品类）+ $0.40 | Managed Payments（已包含） | 因品类而异；可额外购买推广 listing |
| Shopify | 0%（仅平台） | 2.9% + $0.30（Shopify Payments） | $39–$399/月订阅；使用第三方渠道另有 2% 附加费 |
| WooCommerce | 0%（仅平台） | 取决于所选渠道 | 托管、域名、插件为独立成本 |

规律很一致：marketplace 按交易收取更高费用，但包含需求流量。独立平台按交易收取更低费用，但需要你自带（或自建）流量。

## 从单笔订单利润开始

每个渠道都建议按同一公式核算：

```text
客户支付金额
- 平台费用
- 支付处理费
- 广告或获客成本
- 商品成本
- 运费和包装成本
- 退款与客服预留
= 真实贡献利润
```

[Etsy 利润计算器](/tools/ecommerce/etsy-fee-calculator) 适合估算平台侧成本；[Stripe 手续费计算器](/tools/ecommerce/stripe-fee-calculator)、[PayPal 手续费计算器](/tools/ecommerce/paypal-fee-calculator) 和 [Stripe vs PayPal 手续费对比计算器](/tools/ecommerce/stripe-vs-paypal-fee-calculator) 适合估算独立支付侧成本。

### 实例计算：Etsy vs 独立站

假设一个 $50 手工商品，向买家收取 $5 运费，直接成本 $18（材料、包装）。

**Etsy 场景：**

```text
客户支付: $55.00
- 上架费: $0.20
- 交易费 (6.5%): $3.58
- 支付处理 (3% + $0.25): $1.90
- 直接成本: $18.00
- 运费成本: $6.00
- 贡献利润: $25.32
```

**独立站场景（Stripe，自有流量）：**

```text
客户支付: $55.00
- Stripe 手续费 (2.9% + $0.30): $1.90
- 直接成本: $18.00
- 运费成本: $6.00
- 获客成本（广告、内容、SEO）: $5.00
- 贡献利润: $24.10
```

独立站支付处理费更低（$1.90 vs. $5.48），但 $5 获客成本缩小了利润差距。如果店铺能通过自然搜索或邮件以 $3 以下获取客户，独立站就明显更盈利。如果平均获客成本是 $8，Etsy 更优。

比较渠道时，应看所有成本之后的全渠道利润，而不是只看 Etsy 费用和 Stripe 费用的表面差异。

## 支付方式组合优化

同一结账页中不同支付方式的成本不同：

| 支付方式 | 典型附加成本 | 影响 |
|----------|-------------|------|
| 国内信用卡/借记卡 | 基准费率 | 成本最低 |
| 国际卡 | +1.5% | 对全球卖家影响显著 |
| 数字钱包（Apple Pay、Google Pay） | 与底层卡相同 | 中性，适用卡费率 |
| PayPal 钱包 | PayPal Checkout 费率（更高） | 可高出卡费率 0.5-1% |
| BNPL（Afterpay、Klarna、Affirm） | 交易额的 4-6% | 最高，但能提高客单价 |
| ACH / 银行借记 | Stripe 0.8% 封顶 $5 | 大额交易最便宜 |

对于平均客单价 $100 的店铺，$500 以上的发票提供 ACH 选项，每笔可比卡支付省 $10+。代价是 ACH 需要 4-5 个工作日到账，而卡支付 2 天到账。

### BNPL：贵但可能值得

先买后付选项向商家收取交易额的 4-6%，大约是标准卡费率的两倍。但 BNPL 提供商报告显示，提供 BNPL 后平均客单价提升 30-60%。$50 订单按 6% BNPL 费率，成本 $3.00。如果 BNPL 促使客户下了 $75 的订单，额外的 $25 收入按正常利润率计算，可能足以覆盖这笔费用。

判断 BNPL 是否值得保留时，应单独追踪归因于 BNPL 的订单，确认客单价提升能否抵消更高的处理成本。

## Shopify Payments vs 第三方支付渠道

Shopify 商家面临一个重要的渠道选择：

- **Shopify Payments：** Basic 计划 2.9% + $0.30，更高套餐费率递减。无额外交易费。
- **第三方渠道（Stripe、PayPal 等）：** 渠道费率 + Shopify 附加费（依计划为 2%、1% 或 0.5%）。

如果你在 Basic Shopify 计划（$39/月）上直接使用 Stripe，你支付 Stripe 的 2.9% + $0.30 加上 Shopify 的 2% 附加费，合计 4.9% + $0.30，远差于直接使用 Shopify Payments。在 Advanced 计划（$399/月）上，附加费降至 0.5%，第三方渠道才更具竞争力。

对大多数 Basic 或 Standard 计划的 Shopify 商家，Shopify Payments 在费率上明显胜出。只有需要 Shopify Payments 不提供的功能（特定风控工具、自定义结账流程、多币种需求）时，才考虑在 Shopify 上使用第三方渠道。

## 国际销售：了解完整成本叠加

跨境销售会叠加多层成本，常常让卖家意外：

| 成本层 | Etsy | 独立站（Stripe） | 独立站（PayPal） |
|--------|------|-----------------|-----------------|
| 国际交易附加费 | 不适用（交易费统一 6.5%） | 国际卡 +1.5% | 国际商业交易 +1.50% |
| 货币转换 | 2.5%（listing 币种 ≠ 支付币种） | +1%（展示币种 ≠ 结算币种） | 基础汇率上 +3-4% 价差 |
| 监管运营费 | 是（因买家国家而异） | 否 | 否 |
| 物流复杂度 | 部分国际路线可用 Etsy labels | 自主管理 | 自主管理 |

Etsy 统一 6.5% 的交易费对国际订单反而是个优势，它不会因为跨境交易而增加。Etsy 上的主要国际成本是 2.5% 货币转换费和适用的监管运营费。

独立站的国际订单需承担 1.5% 卡附加费和货币转换费。如果你的店铺 30%+ 是国际订单，应将这些成本纳入定价，或考虑按买家国家显示不同价格的 geo-pricing。

## 拒付、欺诈和风险成本

欺诈和拒付是一层容易被忽略的成本，直到它发生：

- **拒付费：** $15（Stripe，胜诉退还）或 $20（PayPal，不总退还）。
- **欺诈监控工具：** Stripe Radar（每笔筛查交易 $0.02–$0.05）。PayPal 卖家保护已包含。
- **3D Secure：** 欧洲 SCA 合规必需。可减少欺诈但可能增加结账摩擦。

一个年处理 $100,000 的店铺，0.3% 拒付率意味着每年 30 笔拒付。按每笔 $15–$20 算，仅拒付费就是 $450–$600，还不算每笔败诉拒付中损失的商品或服务价值。

投入欺诈预防，清晰的产品描述、带追踪的物流、及时响应的客服、在适当场景使用 3D Secure，通常成本低于它能防止的拒付损失。

## 现金流和到账时间

不同渠道释出资金的节奏不同：

| 渠道 | 标准到账 | 备注 |
|------|----------|------|
| Etsy | 每周（合资格卖家可每日） | 新店铺有资金保留 |
| Stripe | 2 个工作日（美国） | 即时到账可用（1% 费用） |
| PayPal | 1-3 个工作日 | 即时到账可用（1.5% 费用） |
| eBay | 1-2 个工作日（Managed Payments） | 部分品类有更长的保留期 |
| Amazon Handmade | 双周（净 14 天） | 标准到账最慢 |

对于现金流紧张的小企业，Etsy 每日到账和 Amazon 双周到账之间的差异，可能影响库存采购和运费覆盖能力。在选择优先发展哪个渠道时，要将到账时间纳入营运资金需求考量。

## 跨渠道税务合规

不同渠道的销售税、VAT 和 GST 处理方式不同：

- **Etsy：** 在美国大多数州和许多国际司法管辖区代你收取并缴纳销售税。这是重要的运营优势。
- **Stripe：** 提供 Stripe Tax（付费附加）自动计税和征收。没有它，你需要手动管理税率。
- **PayPal：** 不会自动计算或征收税费。你在 PayPal 账户或发票工具中手动设置税率。
- **Shopify：** 大多数地区内置计税功能。征收但不代你缴纳。

美国、欧盟和英国的 marketplace facilitator 法规意味着 Etsy、eBay、Amazon 等平台替你处理税务。独立站必须自行管理税务合规。税务自动化工具的成本（通常 $20–$100/月）应计入独立站的成本模型。

## 多渠道策略：什么时候用哪个

大多数成功的小型电商企业使用多个渠道。常见模式：

1. **Etsy** 用于发现和新客获取。接受更高费用，将其视为获客成本。
2. **独立站（Shopify/WooCommerce + Stripe）** 用于复购客户和更高利润的直销。在包裹中加入卡片，邀请买家下次在独立站购买。
3. **PayPal** 作为独立站的辅助支付选项，服务偏好钱包结账的买家。
4. **Amazon Handmade 或 eBay** 作为次级 marketplace，如果它们能触达不同的买家群体。

关键是追踪客户来源。如果一位 Etsy 买家成为你独立站的复购客户，第一笔订单上更高的 Etsy 费用实际上就是获客成本，而且相比付费广告，这笔获客成本可能相当低。

## 核心要点

1. Etsy 费用和支付处理费属于不同类型成本，Etsy 包含流量获取，支付渠道不包含。
2. Stripe 和 PayPal 降低的是支付处理层，不会自动解决流量成本。
3. 净利润取决于客单价、直接成本、转化率、退款、广告、欺诈、税务和复购行为。
4. BNPL 单笔成本更高，但可能将客单价提升到足以覆盖费用的程度。
5. 国际订单在每个渠道上都有额外成本层，Etsy 的统一交易费反而是优势。
6. 到账时间和税务合规是隐性成本，影响营运资金和运营复杂度。
7. 卖家应使用真实场景比较，而不是只看表面百分比。
8. 健康的电商策略可以用 Etsy 获客，用独立站承接复购利润，用 PayPal 做结账补充。
