# Stripe vs PayPal 手续费对比：哪个收款渠道更便宜？

很多人比较 Stripe 和 PayPal 时，会直接说「Stripe 是 2.9%，PayPal 是 3.49%」。这个说法太粗了。真正影响成本的是付款方式、交易金额、固定费、国际交易、货币转换、买家信任和结账体验。

这篇文章只讨论费用和净到账。你可以打开 [Stripe vs PayPal 手续费对比计算器](/tools/ecommerce/stripe-vs-paypal-fee-calculator)，输入自己的订单金额，直接看两个渠道的差额。

## 基础费率对比

以美国常见线上收款场景为例：

| 渠道 / 付款类型 | 常见公开费率 |
|-----------------|--------------|
| Stripe 国内在线卡付款 | 2.9% + $0.30 |
| PayPal Checkout | 3.49% + 固定费 |
| PayPal 标准信用卡/借记卡付款 | 2.99% + 固定费 |
| PayPal Goods & Services | 2.99% |

一笔 $100 的国内付款：

```text
Stripe: $100 × 2.9% + $0.30 = $3.20 手续费
PayPal Checkout: $100 × 3.49% + $0.49 = $3.98 手续费
差额: $0.78
```

这不代表 Stripe 永远更好，而是说明费用比较应该先看净到账，再看业务场景。

|---:|---:|---:|---:|---:|
| $5.00 | $0.45 | $0.66 | $0.64 | $0.21 |
| $10.00 | $0.59 | $0.84 | $0.79 | $0.25 |
| $25.00 | $1.03 | $1.36 | $1.24 | $0.33 |
| $50.00 | $1.75 | $2.24 | $1.99 | $0.49 |
| $100.00 | $3.20 | $3.98 | $3.48 | $0.78 |
| $250.00 | $7.55 | $9.22 | $7.97 | $1.67 |

| $1,000.00 | $29.30 | $35.39 | $30.39 | $6.09 |

核心洞察：在每个价格点上，Stripe 的国内卡付款都更便宜，但 $100 以下交易，绝对差额不到 $1。对低客单价卖家来说，费率差异可能不如转化率和买家偏好重要。

## 固定费会改变结果

固定费对小额交易影响很大。Stripe 的 $0.30 和 PayPal Checkout 的 $0.49 在 $500 发票里都不明显，但在 $5 数字文件或低价模板中会显著拉高有效费率。

| 订单金额 | Stripe 有效费率 | PayPal Checkout 有效费率 | PayPal Card 有效费率 |
|---:|---:|---:|---:|
| $5.00 | 9.0% | 13.2% | 12.8% |
| $10.00 | 5.9% | 8.4% | 7.9% |
| $25.00 | 4.1% | 5.4% | 5.0% |
| $50.00 | 3.5% | 4.5% | 4.0% |
| $100.00 | 3.2% | 4.0% | 3.5% |

$10 的交易，两个渠道的有效费率都远超标语百分比。如果平均客单价低于 $25，固定费才是成本的主要驱动因素——不是百分比。

### 小额付款对比

PayPal 的小额付款费率（5% + $0.05）会显著改变低客单价对比：

| 订单金额 | Stripe (2.9% + $0.30) | PayPal 小额 (5% + $0.05) | 胜出 |
|---:|---:|---:|---:|
| $5.00 | $0.45 | $0.30 | PayPal |
| $10.00 | $0.59 | $0.55 | PayPal |
| $12.00 | $0.65 | $0.65 | 持平 |
| $15.00 | $0.74 | $0.80 | Stripe |

$12 以下的交易，PayPal 小额付款费率实际上可能比 Stripe 更便宜。如果你的业务模式涉及大量 $10 以下的交易，使用 PayPal 小额付款费率可能是主流渠道中最低费的选择。

## 国际卡和货币转换会改变判断

国际付款会让费用对比发生变化。

**Stripe** 对国际卡在国内卡费率基础上加收约 1.5%，当结算币种与收款币种不同时再加 1% 货币转换费。

**PayPal** 对国际商业交易在国内费率基础上叠加 1.50%，再加上通常为基础汇率 3-4% 的货币转换价差。

以一笔 $100 国际付款为例：

```text
Stripe（国际卡，USD 结算）:
$100 × (2.9% + 1.5%) + $0.30 = $4.70

PayPal Checkout（国际交易，USD 收款）:
$100 × (3.49% + 1.50%) + $0.49 = $5.48

差额: $0.78（与国内相同的绝对差额，但两者都更高了）
```

在百分比层面，国际附加费适用后，Stripe 和 PayPal 的差距会缩小。但如果涉及货币转换，PayPal 的 3-4% 价差可能使其明显比 Stripe 的 1% 转换费更贵。

如果你的买家大多来自本国，用国内费率估算通常够用；如果你的买家分布在多个国家，就应该按真实买家结构估算综合费率，而不是假设所有订单都是国内付款。

## 交易费之外：完整成本画像

### 争议和拒付费

| 费用类型 | Stripe | PayPal |
|----------|--------|--------|
| 拒付费 | $15 | $20（通常） |
| 争议费 | 不适用（通过拒付流程处理） | $8–$16（拒付前的争议） |
| 胜诉后退还拒付费 | 是（退还 $15） | 不总是 |

Stripe 的拒付费更低，且胜诉后退还。PayPal 的两级体系（争议 → 拒付）意味着如果问题升级，你可能需要承担两笔费用。

### 退款处理

| 方面 | Stripe | PayPal |
|------|--------|--------|
| 百分比费退还 | 是 | 是 |
| 固定费退还 | 否（但近期政策中 Stripe 已不在退款时保留固定费） | 否（保留 $0.49） |

Stripe 退款时不保留固定费，这对退货率较高的商家可以省下一笔钱。PayPal 每笔退款都会保留 $0.49 固定费。

### 到账时间

| 渠道 | 标准到账 | 即时到账选项 |
|------|----------|------------|
| Stripe | 2 个工作日（美国） | 可用（1% 费用，最低 $0.50） |
| PayPal | 1-3 个工作日 | 可用（1.5% 费用，最低 $0.25） |

到账时间会影响小企业的现金流。如果需要当日到账，可以比较即时到账费用。对大多数商家，标准到账的 1-2 天差异可以忽略。

## Stripe 常见优势场景

Stripe 往往更适合：

- 需要嵌入式 checkout 的独立站
- 以信用卡/借记卡付款为主的业务
- SaaS 订阅和用量计费
- 需要更强 API 和 webhook 基础设施的开发团队
- 需要详细支付事件数据的产品
- 标准美国国内卡付款成本敏感的场景
- 国际卡和货币转换成本更低的场景
- 需要机器学习欺诈防护（Stripe Radar）

对 SaaS 和软件产品而言，Stripe 的计费引擎（Stripe Billing）可以处理按比例计费、阶梯定价、用量计费和催款管理——这些功能远超简单的循环收款。

## PayPal 常见优势场景

PayPal 仍然适合：

- 买家更信任 PayPal 钱包
- 品牌还在建立信任，需要降低付款顾虑
- 需要快速发票或 payment link，没有开发资源
- 国际买家熟悉 PayPal
- 希望把 PayPal 作为补充支付方式，而不是唯一方式
- 小额付款费率在 $12 以下交易中比 Stripe 更便宜
- 想要开箱即用的卖家保护，不想额外配置风控工具

即使 PayPal 手续费略高，如果它能提升转化率，也可能值得保留。一笔 $50 订单 1% 的费率差只有 $0.50。如果 PayPal 能将转化率提升哪怕 2%，它就能为自己买单。

## 功能对比矩阵

| 功能 | Stripe | PayPal |
|------|--------|--------|
| 托管结账页 | Stripe Checkout | PayPal Checkout |
| 嵌入式/无头结账 | Stripe Elements | PayPal JavaScript SDK |
| 循环订阅 | Stripe Billing | PayPal Subscriptions |
| 发票 | Stripe Invoicing | PayPal Invoices |
| 虚拟终端 | 有限支持 | PayPal Virtual Terminal |

| ACH/银行转账 | 是（ACH、SEPA、Bacs 等） | 有限支持 |
| BNPL/先买后付 | Stripe（通过 Affirm、Klarna 等） | PayPal Pay Later |

功能对比和费率对比同样重要。如果你需要 Stripe Connect 做平台或者 Stripe Billing 做复杂订阅，费率差异在能力需求面前是次要的。

## 不要只比较一笔订单

更合理的比较方式是看真实订单结构：

| 指标 | 为什么重要 |
|------|------------|
| 平均客单价 | 固定费对低客单价影响更大 |
| 国内/国际买家比例 | 附加百分比会叠加 |
| 退款率 | PayPal 保留固定费；Stripe 不保留 |
| 争议率 | 两者都有拒付费，PayPal 还有额外争议费 |
| 付款方式结构 | 钱包、卡、Pay Later、银行付款费率不同 |
| 转化率 | 低费率如果降低成交，也未必划算 |
| 开发资源 | Stripe API 需要更多初始设置 |
| 到账时间需求 | 即时到账费用两个渠道不同 |

先用 [Stripe vs PayPal 手续费对比计算器](/tools/ecommerce/stripe-vs-paypal-fee-calculator) 做初步判断，再用真实月度报表复核。

## 是否应该两个都提供？

很多电商网站会同时提供 Stripe 和 PayPal。Stripe 作为主卡处理器，PayPal 作为买家信任和钱包支付补充。尤其是跨境销售或新品牌，PayPal 的存在可能降低付款犹豫。

代价是运营复杂度增加：你需要对账两个后台、维护两套设置，并处理不同的退款和争议流程。如果两个都开，建议明确记录各自适用场景和月度核算方式。

一个对中小店铺实用的配置：

- **主力：** Stripe 处理卡付款（更低费率，更好开发体验）。
- **补充：** PayPal 满足钱包信任和国际买家偏好。
- **监控：** 3 个月后，查看各渠道的结账转化率。如果某个渠道在完成付款上明显更优，调整各自在结账页的展示优先级。

### 国家/地区覆盖

Stripe 在 46+ 个国家可用。PayPal 覆盖 200+ 个市场。如果你卖给 Stripe 不支持商户注册的国家的买家，PayPal 可能是你接受国际付款的唯一选择。在选择单一渠道策略之前，先查看两个渠道的国家支持页面。

## 核心要点

1. Stripe 在美国标准国内在线卡付款中，每个价格点通常都更便宜。
2. PayPal 小额付款费率在 $12 以下交易中可以跑赢 Stripe。
3. PayPal Checkout 可能更贵，但在某些市场能提高买家信任和结账完成率。
4. 两个渠道的固定费都会让小额交易的有效费率远高于标语百分比。
5. 国际卡和货币转换会改变对比结果，PayPal 的转换价差通常是更大的成本项。
6. Stripe 退款时退还固定费；PayPal 不退还。这对高退货率业务很重要。
7. 功能需求（订阅、平台、风控工具）可能比费率差异更能驱动最终决策。
8. 最好的渠道要看手续费、转化率、退款、争议和运营成本之后的综合净结果。
