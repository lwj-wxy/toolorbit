# Stripe vs PayPal 手续费对比：哪个收款渠道更便宜？

很多人比较 Stripe 和 PayPal 时，会直接说「Stripe 是 2.9%，PayPal 是 3.49%」。这个说法太粗了。真正影响成本的是付款方式、交易金额、固定费、国际交易、货币转换、买家信任和结账体验。

这篇文章只讨论费用和净到账。你可以打开 [Stripe vs PayPal 手续费对比计算器](/tools/ecommerce/stripe-vs-paypal-fee-calculator)，输入自己的订单金额，直接看两个渠道的差额。

## 基础费率对比

以美国常见线上收款场景为例：

| 渠道 / 付款类型 | 常见公开费率 |
|-----------------|--------------|
| Stripe 国内在线卡付款 | 2.9% + $0.30 |
| PayPal Checkout | 3.49% + 固定费 |
| PayPal 标准信用卡/借记卡付款 | 2.99% + 固定费 |
| PayPal Goods & Services | 2.99% |

一笔 $100 的国内付款：

```text
Stripe: $100 × 2.9% + $0.30 = $3.20 手续费
PayPal Checkout: $100 × 3.49% + $0.49 = $3.98 手续费
差额: $0.78
```

这不代表 Stripe 永远更好，而是说明费用比较应该先看净到账，再看业务场景。

## 固定费会改变结果

固定费对小额交易影响很大。$0.49 在 $500 发票里不明显，但在 $5 数字文件、低价模板或小额捐赠中会显著拉高有效费率。

有效费率的计算方式是：

```text
手续费 ÷ 客户支付金额 × 100 = 有效费率
```

如果 $5 订单产生 $0.66 手续费，有效费率就是 13.2%。这比单纯看 2.99% 或 3.49% 更能反映真实成本。

## 国际卡和货币转换会改变判断

国际付款会让费用对比发生变化。Stripe 会对国际卡和货币转换收取附加费用；PayPal 也会对国际商业交易叠加额外百分比，并且货币转换可能带来汇率价差。

如果你的买家大多来自本国，用国内费率估算通常够用；如果你的买家分布在多个国家，就应该按真实买家结构估算综合费率，而不是假设所有订单都是国内付款。

## Stripe 常见优势场景

Stripe 往往更适合：

- 需要嵌入式 checkout 的独立站
- 以信用卡/借记卡付款为主的业务
- SaaS 订阅和用量计费
- 需要更强 API 控制的团队
- 需要更细支付事件数据的产品
- 标准美国国内卡付款成本敏感的场景

对 SaaS 和软件产品而言，Stripe 的开发体验和自动化能力可能和费率一样重要。

## PayPal 常见优势场景

PayPal 仍然适合：

- 买家更信任 PayPal 钱包
- 品牌还在建立信任，需要降低付款顾虑
- 需要快速发票或 payment link
- 国际买家熟悉 PayPal
- 希望把 PayPal 作为补充支付方式，而不是唯一方式

即使 PayPal 手续费略高，如果它能提升转化率，也可能值得保留。

## 不要只比较一笔订单

更合理的比较方式是看真实订单结构：

| 指标 | 为什么重要 |
|------|------------|
| 平均客单价 | 固定费对低客单价影响更大 |
| 国内/国际买家比例 | 附加百分比会叠加 |
| 退款率 | 退款处理方式影响真实成本 |
| 争议率 | 拒付和争议费用会影响利润 |
| 付款方式结构 | 钱包、卡、Pay Later、银行付款费率不同 |
| 转化率 | 低费率如果降低成交，也未必划算 |

## 是否应该两个都提供？

很多电商网站会同时提供 Stripe 和 PayPal。Stripe 作为主卡处理器，PayPal 作为买家信任和钱包支付补充。尤其是跨境销售或新品牌，PayPal 的存在可能降低付款犹豫。

代价是运营复杂度增加：你需要对账两个后台、维护两套设置，并处理不同的退款和争议流程。如果两个都开，建议明确记录各自适用场景和月度核算方式。

## 核心要点

1. Stripe 在美国标准国内在线卡付款中通常费用更低。
2. PayPal Checkout 可能更贵，但在某些市场能提高买家信任。
3. 固定费会让小额交易的有效费率变高。
4. 国际卡和货币转换会改变最终对比。
5. 最好的渠道要看手续费、转化率、退款、争议和运营成本之后的综合净结果。
