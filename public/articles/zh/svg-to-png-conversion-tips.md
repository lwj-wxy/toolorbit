## SVG 转 PNG：如何减少模糊、字体丢失和样式问题

可缩放矢量图形 (SVG) 基于路径和形状描述，不依赖固定分辨率。即便如此，你仍可能需要把 SVG 转成 PNG。

答案在于**生态兼容性**。虽然 SVG 是现代 Web 的理想选择，但无数的老旧平台、原生的移动端框架（某些配置下）、社交媒体平台抓取工具（如 Open Graph 分享图）甚至是办公软件（Word / PPT 较老版本），都仍然严格要求使用光栅化图像格式（如 JPG/PNG）。

SVG 转 PNG 时，问题通常来自分辨率、字体、滤镜和 `viewBox` 设置。转换前检查这些点，可以减少模糊和样式丢失。

### 为什么转换过程中会发生质量损失？

SVG 使用 XML 标签来描述形状（路径、圆、多边形）和渐变。而 PNG 只是一个由一个个方形彩色像素组成的网格矩阵。

当我们将 SVG 转换为 PNG 时，会发生一个称为 **“光栅化” (Rasterization)** 的计算过程。渲染引擎必须计算出网格上的哪些物理像素应该被着色，从而“近似”地显示出矢量形状。

1. **网格密度不足（低分辨率）：** 如果你将其渲染到一个非常小的网格上（例如只请求转换为 100x100 像素），平滑的曲线在物理上就会变成阶梯状的锯齿。
2. **字体丢失：** 如果 SVG 内部使用自定义字体的 `<text>` 标签，而转换工具或服务器没有安装该字体，渲染结果会回退到默认字体。
3. **复杂的滤镜支持不佳：** 许多简单的格式转换代码库无法理解高阶的 SVG 滤镜（例如 `feGaussianBlur` 阴影），或者 CSS 混合模式，导致转换出来的 PNG 丢失元素或变黑。

### 核心技巧 1：使用超采样 (Over-Sampling)

既然 SVG 是矢量图，这就意味着在源文件大小不增加哪怕 1 KB 的前提下，你可以将其放大到任意尺寸。

不要只按最终显示尺寸导出 PNG。可以用 2 倍或 4 倍尺寸导出，再缩小显示。

假如你最终需要一张 500x500 的配图，可以请求转换工具生成 2000x2000 像素的 PNG。然后用 CSS 缩小它 (`width: 500px`)，或用缩放算法下采样。更高分辨率渲染能改善抗锯齿边缘。

### 核心技巧 2：轮廓化所有字体（文本转路径）

这是设计和开发交接中常见的问题。不要假设自动化转换 API 或同事电脑里安装了你的商业字体。

**解决方案：** 转换前，必须在矢量编辑器（Figma, Illustrator, Sketch）中将所有的文本节点转换为具体的矢量图形路径（Outline）。
* **在 Figma 中：** 右键单击文本图层 -> 选择 "Outline Stroke" (快捷键 Shift + Cmd + O)。
* **在 Illustrator 中：** 菜单栏选择 "文字" -> "创建轮廓"。

完成后，文字会变成几何路径。转换引擎不再依赖字体文件，视觉结果更稳定。

### 核心技巧 3：将内联 CSS 与动态滤镜压平

有时用网页工具导出的 SVG 高度依赖于内部的 `<style>` 标签或者使用 CSS 变量来控制颜色。但当使用 ImageMagick 等纯粹的图形库进行后端转换时，这些样式很可能会被直接忽略。

**解决方案：** 尽可能把所有的表现层属性（Presentation Attributes）直接内联写入相关的图形节点元素中。

**不推荐的做法：**
```xml
<style> .my-primary { fill: #00FF00; } </style>
<circle class="my-primary" cx="50" cy="50" r="40" />
```

**兼容性更好的做法：**
```xml
<circle fill="#00FF00" cx="50" cy="50" r="40" />
```
这种写法更容易被服务器端转换工具读取和渲染。

### 核心技巧 4：用 ViewBox 控制缩放

检查 SVG 源码，确认它使用 `viewBox` 描述内部坐标系，而不是只写死宽高像素值。

* **糟糕的设定：** `<svg width="512" height="512">`
* **更好的设定：** `<svg viewBox="0 0 512 512" width="100%" height="100%">`

如果只使用绝对宽高，当你要求转换器输出 4000x4000 图片时，它可能只在左上角 512x512 区域绘制内容，其余部分留白。使用 `viewBox` 后，内部元素可以按目标画布等比例缩放。

### 结语

SVG 转 PNG 时，先提高导出分辨率，再把字体转路径，内联关键样式，并检查 `viewBox`。这些步骤能减少模糊、字体替换和留白问题。可以使用 ToolOrbit 的转换工具完成导出前检查和格式转换。
