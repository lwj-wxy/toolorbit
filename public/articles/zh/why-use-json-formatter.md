## 为什么需要 JSON 格式化工具

JSON (JavaScript Object Notation) 是 Web API、配置文件和日志里最常见的数据格式之一。机器适合读取压缩后的 JSON，人排查问题时需要结构化视图。

生产 API 常返回最小化 JSON，去掉空格和换行。机器解析没问题，但人很难在一长串文本里定位字段、括号和数组层级。

JSON 格式化工具的作用不只是加缩进，还包括校验、折叠、排序和隐私保护。

### 1. 结构级校验与精准查错感知
`Uncaught SyntaxError: Unexpected token } in JSON at position 8594` 这类错误很常见。格式化工具可以定位多余逗号、未闭合引号、错位括号和非法字符。面对几千行 JSON，比人工数括号可靠得多。

### 2. 深度节点遍历与折叠能力 (Folding)
现代 API 经常返回多层嵌套数据，GraphQL 或聚合报表里尤其常见。

排查时，你可能只关心 `metadata.users.permissions[4]`。折叠功能可以隐藏无关数组和对象，让你直接定位目标节点。

### 3. 依据字母表排序消除对比干扰 (Lexical Sorting)
如果你导出两份前端状态快照，字段顺序不同会让 Diff 结果变得很吵。

按字母顺序排序 Key 后，两份 JSON 的结构更容易对比。这样 Diff 更容易突出真正变化的值，而不是字段顺序。

### 4. 零信任网络时代的数据隐私铁律
开发者经常处理包含敏感信息的 JSON：手机号、订单信息、内部配置、鉴权密钥或日志片段。

不要把这些内容粘贴到来源不明的在线工具。更安全的工具应在浏览器本地解析和格式化，不把内容上传到服务器。

### 结语
JSON 格式化工具能帮助你校验结构、定位字段、折叠深层节点、排序 Key 并减少敏感数据外传风险。排查接口问题时，它比手动阅读压缩 JSON 更可靠。
